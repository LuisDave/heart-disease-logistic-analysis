# Datos

- `raw/heart.csv`: archivo original proporcionado para el análisis.
- `processed/heart_clean.csv`: versión reproducible generada por `python run_analysis.py` después de eliminar duplicados exactos.

El archivo original contiene 1,025 filas. El análisis detecta 723 duplicados exactos y trabaja con 302 observaciones únicas para evitar tratar repeticiones idénticas como evidencia independiente.
